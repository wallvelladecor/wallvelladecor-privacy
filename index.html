Automation Privacy Policy

Last Updated: November 2, 2026

1. Introduction

WallVellaDecor Automation is a private application designed to publish product-related Pinterest Pins for the WallVellaDecor Etsy shop.

2. Information Accessed

The application may access public Etsy product information, including titles, descriptions, images, and product URLs. It may also access authorized Pinterest boards, Pins, account information, and basic analytics.

3. How Information Is Used

Information is used to create and schedule organic Pinterest Pins, organize content into relevant boards, link Pins to Etsy listings, prevent duplicate publishing, and monitor content performance.

4. Data Sharing

Product content is shared with Pinterest for publication. The application is intended solely for the authorized WallVellaDecor account owner. Personal information is not sold.

5. Data Security

API credentials and authentication tokens are stored using restricted-access secrets or environment variables. The application does not intentionally collect customer payment information.

6. Data Retention and Deletion

Operational records are retained only as needed for automation. The account owner can revoke API access and delete stored application records.

7. Third-Party Services

This application uses the Etsy and Pinterest APIs. Their respective privacy policies and terms also apply.

8. Policy Updates

This policy may be updated when application functionality or data practices change.
